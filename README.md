# كوت بو ستة أونو (Kuwaiti Kout Bo 6 - Uno Edition) 🇰🇼🃏

لعبة كوت بو ستة الكويتية الأصلية بقواعد الديوانية الكاملة مدمجة مع نظام كروت أونو (UNO) الشهيرة، مع نظام الذكاء الاصطناعي للبوتات، وإدارة الطاولات الخاصة، وتوافق كامل مع جميع الشاشات (الهواتف، الفولد، الفليب، الأجهزة اللوحية، والكمبيوتر).

---

## 🌟 المميزات
- **نظام كوت بو ستة الكويتي الأصيل:**
  - قوة الأوراق: الجيكر (+4)، خال الحكم (1 الحكم)، الميكر (Rainbow)، كروت الحكم (+2، ⊘، ⇄، 0 إلى 2).
  - اتجاه اللعب والمزايدة عكس عقارب الساعة (لليمين ↺).
  - المزايدة من 5 إلى 8، والباون (9 أكلات)، والملزوم للموزع، والفوز بالعسم (51-0 أو باون الجولة الأولى).
  - رسالة الفوز عند كسب الخصم المشتري: **"يابوها"**!
- **طاولة خاصة وغرف برمز 4 أرقام:**
  - إمكانية حجز المقاعد للاعبين أو ملء الطاولة ببوتات ذكية بنقرة واحدة.
  - مشاركة سريعة عبر واتساب أو نسخ الرابط.
- **توافق تام مع جميع الشاشات (Fold, Flip, Tablet, Desktop):**
  - متجاوبة 100% بدون أي قص للأزرار أو الطاولة.
- **مؤثرات صوتية تفاعلية للديوانية** وأصوات توزيع ورمي الكروت.

---

## 🚀 التشغيل محلياً (Run Locally)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`
